# Основные функции приложения

1) регистрация и авторизация в программе 
2) создание уведомления 
3) удаление уведомления
4) редактирование уведомления
5) календарь, где отображаются все уведомления(даты выделены соответствующим цветом, который зависит от важности уведомления)
6) уведомления из самой программы или Windows
7) программа будет работать в фоновом режиме или с окном(чтобы выйти из фонового режима нужно нажать комбинацию из клавиш Ctrl+Shift+H) 
8) программа будет работать всегда, когда мы хотим уведомления
9) возможность делиться файлом с напоминаниями, которые можно загрузить в программу
